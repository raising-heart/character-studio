# Workflow origin

Character Studio is a personal customization inspired by the plan → implement → asset pipeline → visual QA structure of OpenAI Game Studio 0.1.2:
https://github.com/openai/plugins/tree/main/plugins/game-studio

The instructions and helper scripts here are newly written for Blender character work. No Game Studio source files are bundled. Character Studio is not an official OpenAI or Blender Foundation plugin and does not change the installed Game Studio plugin.
