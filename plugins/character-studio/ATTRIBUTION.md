# Workflow origin

Character Studio is a personal customization inspired by the plan → implement → asset pipeline → visual QA structure of OpenAI Game Studio 0.1.2:
https://github.com/openai/plugins/tree/main/plugins/game-studio

The Blender helpers and instructions are authored for Character Studio, with the reviewed MIT geometry and workflow adaptations recorded in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). No Game Studio source files are bundled. Character Studio is not an official OpenAI or Blender Foundation plugin and does not change the installed Game Studio plugin.
